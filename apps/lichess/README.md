# Lichess

[Lichess](https://lichess.org) is free, open-source chess (AGPL), with no ads. Its web site already has a phone layout, so this app is only the site in its own Chromium window, with an icon in the app grid.

```sh
apps/install lichess
```

The icon is fetched from lichess.org when you install. Logging in is optional; the profile is the app's own, in `~/.local/share/android2linux/apps/lichess/profile`.
