# Brand

The mark is three tiles in the style of a Metro start screen: a wide tile with a shell prompt (`>_`) cut out of it, and two small tiles below. A phone interface you put together yourself, with a terminal in it.

| File | Use |
|---|---|
| `symbol.svg` | The mark in the brand colour |
| `symbol-black.svg`, `symbol-white.svg` | One colour, on light or dark backgrounds |
| `symbol-small.svg`, `symbol-small-black.svg` | 32 px and smaller: wider gaps and a heavier prompt |
| `lockup-light.svg`, `lockup-dark.svg` | Mark and name, on light and dark backgrounds (the README header) |
| `lockup-black.svg`, `lockup-white.svg` | Mark and name in one colour |
| `avatar.svg`, `avatar.png` | The GitHub organisation avatar (500×500) |
| `social-preview.svg`, `social-preview.png` | The repository's social preview (1280×640) |

## Colour

| | HEX | RGB |
|---|---|---|
| Magenta | `#D80073` | 216 0 115 |
| Ink | `#1B1B1B` | 27 27 27 |

White on magenta has a contrast ratio of 5.0:1.

## Type

The name is set in lowercase [Selawik](https://github.com/microsoft/Selawik) Semilight (SIL Open Font License 1.1), tracked −1 at 120 units, and outlined, so the files need no font.

## Use

- Keep clear space around the mark of at least the gap between the tiles × 2.
- Below 32 px, use `symbol-small.svg`.
- Don't recolour the tiles separately, rotate the mark, rearrange the tiles or add effects.
